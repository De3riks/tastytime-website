# TastyTime — демонстраційний сайт кафе (Харків)

Статичний сайт на HTML, CSS і JavaScript. Без збірки, без залежностей, без платних API.

> **Це демонстраційна версія. Сайт не є офіційним сайтом закладу.** Меню, ціни та описи страв — приклад.

## Структура

```
index.html        головна сторінка
css/style.css     стилі
js/main.js        меню, кошик, анімації
js/config.js      налаштування (посилання на Instagram)
images/           фото страв
vercel.json       налаштування Vercel
```

## Перегляд на комп'ютері

Розпакуйте архів і відкрийте `index.html` у браузері. (Шрифти Google Fonts і карта потребують інтернету.)

## Публікація на GitHub

1. Створіть обліковий запис на https://github.com та натисніть **New repository**.
2. Назвіть репозиторій, наприклад `tastytime-demo`, і створіть його.
3. Натисніть **uploading an existing file** і перетягніть **вміст** розпакованої папки (index.html, css, js, images, vercel.json, README.md), а не саму папку.
4. Натисніть **Commit changes**.

## Публікація на Vercel

1. Увійдіть на https://vercel.com через GitHub.
2. **Add New → Project** і виберіть репозиторій `tastytime-demo`.
3. **Framework Preset:** *Other*. Build Command та Output Directory залиште порожніми.
4. Натисніть **Deploy**. За хвилину сайт отримає адресу `*.vercel.app`.

Кожна зміна, завантажена в GitHub, автоматично оновлює сайт.

## Що змінити

- **Instagram:** відкрийте `js/config.js` і вставте підтверджене посилання в `INSTAGRAM_URL`. Кнопка стане активною автоматично.
- **Меню та ціни:** масив `MENU` на початку `js/main.js`.
- **Фото:** замініть файли в `images/` на оригінальні фото закладу (краще від 1200 px по ширині). Поточні фото мають малу роздільну здатність.
- **Контакти:** в `index.html` (адреса, телефон) і посилання карти.

## Примітки

- Кошик демонстраційний: замовлення нікуди не надсилається.
- Відгуки не додавалися навмисно: використовуйте лише справжні.
